# 🍅 在线番茄钟

一个单文件的在线番茄钟计时器，纯静态、无依赖、开箱即用。

**在线访问：<https://zangxyyds.github.io/pomodoro-timer/>**

## 功能

- 实时显示当前系统日期和时间
- 专注 25 分钟 / 短休息 5 分钟 / 长休息 15 分钟，每 4 个番茄自动安排长休息
- 圆形进度环倒计时，模式切换时整页配色随之变化
- 开始 / 暂停 / 重置 / 跳过，标签页标题同步显示剩余时间
- 完成时提示音，专注计时期间保持屏幕常亮
- 今日完成番茄数与专注时长统计（按天自动清零，数据仅保存在访客本地浏览器）
- 可自定义各阶段时长、长休息间隔、自动开始下一阶段
- 快捷键：空格开始/暂停，R 重置，S 跳过
- 深浅色主题自动跟随系统，手机端自适应

## 使用

无需安装和构建，`index.html` 即整个应用，可部署到任意静态托管平台
（GitHub Pages、Vercel、Netlify、Cloudflare Pages 等），或直接双击用浏览器打开。
